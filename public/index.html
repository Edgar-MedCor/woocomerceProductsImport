        Variantes sueltas

        Productos simples cuyo SKU tiene forma de variación (estilo + talla + color), agrupados por estilo. Para convertirlos, en el Excel cambia el Tipo de cada fila a "Variación" y escribe el estilo en "SKU padre". Si el padre no existe, agrega antes una fila Variable con ese SKU; si existe como Simple, cámbiale el Tipo a "Variable".
